# Project Dino

A native C++17 jungle action prototype featuring a pixel-art T-Rex in a 3D obstacle course.

See [the game instructions](game/README.md) for controls and building from source.

Windows downloads will appear on the [Releases page](https://github.com/Enthronite/Testbro/releases). Extract the Windows ZIP before running `project-dino.exe`; keep `SDL2.dll` in the same folder.

This is an early prototype, not a finished game.
